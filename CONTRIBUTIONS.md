# Development provenance and scope

This implementation was created on 2026-10-28 with OpenAI Codex assistance at the
repository owner's request. The Python implementations, first research reports,
notebooks, experiments and automated tests in this delivery were generated with
AI assistance and executed in the development environment. They have not received
an independent human quant review. The owner plans to reimplement and study them;
that planned work is not recorded as already completed.

The original assignment and the existing website predate this implementation and
were preserved. No commits or project dates are backdated. The public experiments
use synthetic inputs and make no claim of historical market performance.

A passing test suite establishes only the checks actually run. It does not prove
full financial correctness, production readiness or an individual's understanding.
Future human changes and reviews should be documented in their actual commits.
