# Quant Derivatives Lab

**Status: Assignment published — pricing engine not yet implemented.**

A progressive Python research portfolio focused on mathematical derivatives pricing, numerical validation, and reproducible experiments. This folder currently contains project specifications only; it does **not** claim to provide a working pricer.

## Project 01 — European Options & Black-Scholes Pricing Engine

[Read the full MSc-level assignment](assignments/01-european-options-black-scholes.md)

**Goal:** derive, implement, and validate analytical European call/put prices under Black–Scholes–Merton, including a constant continuous dividend yield. The resulting library will form the basis for later numerical pricing methods.
